# 雑談における焦点操作と語用動機の分析方針（暫定）

## 目的と分析枠の位置づけ

非タスク指向の雑談を対象に、情報共有の展開を「焦点がどう動いたか」と「その発話にどのような語用的な狙いが読み取れるか」に分けて記述する
ここでいう雑談は、特定の課題の達成ではなく、話すこと自体を目的とする対話を指す
分析するのは記録された発話とその関係であり、次の返答の生成や課題達成の評価は行わない

本方針の出発点は、焦点操作4種類と語用動機5種類からなる依頼者提示の分析枠とする
分類は以下にすべて記載し、外部のプロンプトや会話履歴を前提にしない

| 区分 | 位置づけ |
| --- | --- |
| 依頼者提示の分析枠 | 4操作・5動機を用い、雑談の焦点操作と語用動機を区別して見る |
| 原典の知見 | 発話単位、やりとり、修辞関係、モダリティに関する研究を参照する |
| 本方針での分析上の提案 | 発話の参照先、当該発話の焦点、操作、推定動機、判定上の不確実性を記録し、短い一場面で試行する |

4操作・5動機は、参考文献で提案・検証された分類そのものではない
操作と動機を別々に記録することも分析上の選択であり、両者が統計的に独立しているという主張ではない
対象スクリプトへの適用前であり、分類の妥当性と再現性は今後の試行で確かめる

## 原典から参照すること

### 発話の位置づけと分類基準

荒木ほか（1999）は課題遂行対話を対象に、当初は別々だった発語内行為・ムード・やりとりの観点を統合し、やりとりの中の位置と決定木によるタグ選択を採用している
評価ではタグ名や文末表現に引かれた不一致も報告しており、分類名だけで判断せず、基準と文脈を確認する必要が読み取れる
この研究の対話構成や一致率を、そのまま本方針の雑談分析に適用することはできない
参照箇所：[第2〜4章、252–259頁](https://www.jstage.jst.go.jp/article/jjsai/14/2/14_251/_pdf/-char/ja)

### 局所的なやりとりと発話内容の関係

徳久・寺嶌（2007）は、先に発話間のやりとりを認定し、その役割を分類している
一つの発話が応答と働きかけの双方を担う場合を扱い、間接応答や問い返しの修辞関係と発話される場面を分析している
問い返しについては、修辞関係の分析に先立って、先行発話との表層的な関係も分類している
雑談の分析対象は一方の話者から他方へ情報を伝える部分に限られ、問い返しの修辞関係分析も情報付加型に絞られている
参照箇所：[第2〜4章、426–434頁](https://www.jstage.jst.go.jp/article/tjsai/22/4/22_4_425/_pdf)

本方針では、ここから先行発話とのつながりを参照先として記録する必要性を読み取る
同論文の Addition と本方針の `add`、Reformulation と `paraphrase` は、対象と判定基準が異なるため同一視しない
修辞関係は詳述・因果などの内容間の関係であり、焦点操作や語用動機とは区別する

### 表現の意味と語用論的効果

井上「モダリティ」は、命題内容に対する判断と聞き手への発話・伝達態度を区別し、表現の意味と文脈で生じる語用論的効果を関連づけて記述している
終助詞の分析では、文法的性質、使用できる文脈、イントネーション、方言差も検討している
参照箇所：[第1・2・4節、133–148頁](https://www2.ninjal.ac.jp/takoni/DGG/09_modarityi.pdf)

本方針では表現と文脈を解釈の手掛かりにするが、モダリティを5動機に直接対応させない
原典が扱う表現の意味、そこから生じる効果、分析者が推定する狙いを分けて扱う

## 分析の単位と文脈

以下は、原典を踏まえた本分析での暫定的な運用とする
分析は発話順に進め、各発話の判定には当該発話とそれまでの文脈だけを用いる
後続発話を使って、過去の発話の焦点・操作・動機を判定し直すことはしない

- 元の発話本文、話者、発話順を保持し、各発話を識別できる番号を付ける
- 話者が発言を担う一回分のターンと、その内部を分析のために区切る発話単位を区別する
- 一つのターンに回答と補足など区別できる部分がある場合は区切り、分割後の各本文に発話番号の枝番を対応づける
- 同じ部分が複数の働きを持つだけの場合は、タグを一つにするための分割は行わない
- どの先行発話を受けているかを番号で記録し、直前以外の発話や複数の発話を参照する場合も残す
- 場面の冒頭など、先行する文脈が不足する箇所では、判断できない項目を保留し、判定上の不確実性として記す

当該発話までの文脈から、回答、補足、問い返しなど、その発話が先行発話とどう関係するかを判断する
その関係は参照先と操作の判定に用い、発話ごとの説明文は記録しない
原典のタグ体系一式を新たな必須分類として導入するものではない

原典のタグ付けには音声を利用した判断が含まれる
文字スクリプトだけを扱う場合、抑揚、間、笑い方などを補って解釈せず、それらが必要な判断は保留する
音声やト書きが利用できる場合も、当該発話時点までに得られる情報に限って用いる

## 焦点操作

当該発話の焦点は、その発話が注目を向けている対象や側面を指す
参加者全員の注目がそこへ移ったことを意味するものではない
先行発話の焦点は参照先の記録から取得し、当該発話の行には重複して記録しない
操作は、参照先の焦点と当該発話の焦点を同程度の細かさで比較して判断する
例えば、先行発話を広く「旅行」、当該発話を細かく「旅行の回数」と捉えただけで移動と判定せず、先行発話ですでに回数が問題になっていなかったかを確認する

| 操作 | 依頼者提示の定義 |
| --- | --- |
| `paraphrase` | 同じ焦点を別表現で受ける（軽い整理、言い換え、確認を含む） |
| `switch` | 現在の焦点と関連する近い概念へ注目を移す（活動から回数、現在から過去、事実から評価への移行など） |
| `add` | 属性、数量、評価、例、具体化、補足、対比など新情報を足す（値更新も含む） |
| `topic_shift` | 現在の焦点系列（関連する焦点をたどる一連の流れ）を閉じ、別話題へ移る |

判定には、次の暫定基準を用いる

- `paraphrase` は、確認や疑問の形だけで決めず、同じ焦点を受け直しているかを見る
- `switch` は何から何へ注目を移しているか、`add` は何に対してどの情報が加わったかを確認する
- 評価や具体化などは `switch` と `add` の両方に関わりうるため、機械的な優先順位を設けない
- `topic_shift` は新しい単語の出現だけで決めず、それまでの焦点の連なりと新しい話題との関係を見る
- 相づちや笑いは形だけで分類対象から外さず、焦点への働きが記述できるかを確認する

同じ箇所に複数の操作が認められることと、どの操作か判定できないことを区別する
判定できない場合は、分類に当てはまらないのか、複数の解釈が残るのか、情報が不足するのかを「判定上の不確実性」に記す

## 語用動機

語用動機は、その発話によって理解や関係性、会話進行などをどう調整しようとしているかという解釈を指す

| 動機 | 依頼者提示の分類で読み取る狙い |
| --- | --- |
| `affiliation` | 距離感、共感、面子、関係性を整える |
| `self_interest` | リスク、境界、立場を守る |
| `play` | 軽さ、冗談、誇張、からかい、意外性を作る |
| `epistemic` | 理解合わせ、認識修正、整理、精度向上を図る |
| `meta` | 会話進行、順序制御、切替、段取りを整える |

言い回し、発話の位置、当該発話時点までの場面情報から動機を推定し、選んだ分類を「推定動機」に記録する
この値は推定による選出結果であり、選択前の候補の一覧ではない
複数の狙いが読み取れることと、どの動機か判定できないことを区別する
判定できない場合は保留し、「判定上の不確実性」にその内容を記す

操作から動機を自動的に決めない
例えば、問い返しを一律に `epistemic` とせず、何を確かめているのか、関心や感情の表明として読めるのかを検討する
感情の表出があること自体も、直ちに `affiliation` や `play` の根拠にはしない

「維持」「展開」などの談話効果を別の必須タグにはしない

## 記録形式

発話番号・話者・本文を保持したスクリプトに、次の分析表を対応させる
一行は一つの分析単位を基本とし、分割した場合は `12a`・`12b` のように元の発話番号に枝番を付ける
各番号に分析対象の本文を対応づけるため、対象範囲の列は設けない

| 発話番号 | 参照する先行発話 | 当該発話の焦点 | 操作 | 推定動機 | 判定上の不確実性 |
| --- | --- | --- | --- | --- | --- |

「参照する先行発話」には、当該発話が応答・言及している先行発話の番号を記録する
「当該発話の焦点」には、その発話が注目を向けている対象や側面を記録する
「操作」と「推定動機」には、それぞれの分類から判定した結果を記録する
「判定上の不確実性」には、判定が定まらない項目とその不確実性だけを記し、該当しなければ空欄にする
各列は一つの項目を表し、セル内で複数の項目を矢印や小見出しによってまとめない
判断根拠を毎行文章化する欄と、後続反応の欄は設けない

## 試行と見直し

1. 対象スクリプトから連続した短い一場面を選び、範囲と利用できる音声・場面情報を記録する
2. 発話順に、当該発話までの情報で参照先、当該発話の焦点、操作、推定動機を判定し、判定上の不確実性があれば記す
3. 記録済みの参照先・焦点・操作を発話順にたどり、焦点の推移を記述する
4. 判断が割れる箇所を、単位の切り方、参照先、焦点の細かさ、操作、動機、情報不足に分けて見直す
5. 判定基準を変えた場合は理由を残し、同じ基準が関わる発話を、それぞれの当該発話までの情報で再判定する

操作の種類や連続回数だけで会話の良否を判定しない
言い換えや情報追加が続く場合も、それぞれの発話時点の文脈に沿って判定する
操作を均等に出現させることや、質問・話題移行を増やすことを分析の目標にはしない

初回の成果物は、一場面の分析表、焦点の推移の記述、判定上の不確実性を踏まえた基準の修正案とする
同じ基準で説明できた箇所と説明できなかった箇所を確認してから対象を広げる
一人による試行だけで再現性を確認済みとはせず、定量評価や複数の分析者による一致率の検証は別途設計する
