# 雑談における焦点操作と語用動機の分析方針（暫定）

## 目的と位置づけ

非タスク指向の雑談を対象に、情報共有の展開を「焦点がどう動いたか」と「その動きにどのような語用的な狙いが読み取れるか」に分けて記述する

ここでいう雑談は、特定の課題の達成ではなく、話すこと自体を目的とする対話を指す
焦点は、その時点で会話の参加者が注目している対象や側面を指し、語用動機は、その発話によって理解や関係性、会話進行などをどう調整しようとしているかという解釈を指す

本方針では、焦点操作を4種類、語用動機を5種類に分けた暫定的な分析枠を用いる
実際の対話スクリプトに適用し、説明できる範囲と判断に迷う境界を確かめる
対象スクリプトへの適用前であり、分類の妥当性はまだ検証していない

分析対象は、すでに起きた発話と会話の展開とする
返答生成やタスク完了の達成度評価は目的にしない

## 分析の単位と文脈

- 発話を前後の流れの中で読み、直前の一発話だけでなく、それまでの話題や参照関係から焦点を再構成する
- 一発話に複数の操作がある場合は必要な箇所だけ区切って記述し、具体的な分割基準は試行で調整する
- 操作を選ぶ前に、焦点の前後を `活動 → 頻度` のように短く記述する
- 後続の反応は、その働きが相手にどう受け取られたかを見る材料とし、話者の動機を確定する証拠とはしない

## 焦点操作

| 操作 | 暫定的な判断基準 |
| --- | --- |
| `paraphrase` | 同じ焦点を別表現で受ける（軽い整理、言い換え、確認を含む） |
| `switch` | 現在の焦点と関連する近い概念へ注目を移す（活動から回数、現在から過去、事実から評価への移行など） |
| `add` | 現在の焦点に属性、数量、評価、例、具体化、補足、対比などの情報を足す（値更新も含む） |
| `topic_shift` | 関連する焦点をたどってきた一連の流れを閉じ、別話題へ移る |

`switch` と `add` は重なりやすいため、「注目先が移ったか」「同じ注目先の情報が増えたか」を区別の目安にする
これは確定した判定規則ではなく、実例で判断が割れる場合は候補と迷いの理由を残す

相づちや笑いなど、4操作に収めにくい発話は無理に分類せず保留する
分類の追加・変更は、試行で得られた事例を踏まえて検討する

## 語用動機

| 動機 | 読み取る狙い |
| --- | --- |
| `affiliation` | 距離感、共感、面子、関係性を整える |
| `self_interest` | リスク、境界、立場を守る |
| `play` | 軽さ、冗談、誇張、からかい、意外性を作る |
| `epistemic` | 理解合わせ、認識修正、整理、精度向上を図る |
| `meta` | 会話進行、順序制御、切替、段取りを整える |

動機は話者の内心を確定するラベルではなく、根拠付きの解釈として扱う
言い回しや直前のやり取りを根拠に候補を付け、複数の解釈がある場合は併記し、判断材料が不足する場合は保留する
操作と動機は別々に判断する

終助詞や推量表現などは解釈の手掛かりにするが、特定の表現と操作・動機を一対一に対応させない

## 会話全体の展開

発話ごとの分類に加えて、操作の連なりを読む
例えば、言い換えを重ねて理解を合わせる流れや、属性を足してから別の経験へ移る流れを記述する

操作の種類や連続回数だけで、会話の良否を判定しない
言い換えの連続を停滞、情報追加の連続を情報過密と決めつけず、繰り返しがその場で何をしているかを文脈から確かめる
複数の操作が混ざること自体も、良い会話の条件とはしない

## 記録形式と進め方

分析記録は、次の表を基本とする

| 発話 | 焦点の前→後 | 操作 | 動機候補 | 判断の根拠・迷い |
| --- | --- | --- | --- | --- |

1. 対象スクリプトから連続した短い一場面を選ぶ
2. 焦点の前後を記述し、操作と動機候補を根拠とともに付ける
3. 操作の連なりを読み、場面全体の展開を記述する
4. 分類の重なり、保留した発話、文脈不足の箇所を確認する
5. 試行結果を踏まえて分類の境界と記録方法を調整してから、対象を広げる

初回の成果物は、一場面の分析表、展開の記述、判断に迷った点の一覧とする
網羅的な分類体系や定量評価の設計は、この段階では確定しない

## 参考資料と本方針との関係

以下の資料は、発話の分類方法、局所的なやりとり、表現と解釈の関係を考えるために参照する
本方針の4操作・5動機は独自の暫定的な整理であり、これらの資料で提案・検証された分類そのものではない

- 荒木雅弘・伊藤敏彦・熊谷智子・石崎雅人（1999）「発話単位タグ標準化案の作成」『人工知能学会誌』14巻2号、251–260頁 — [本文PDF](https://www.jstage.jst.go.jp/article/jjsai/14/2/14_251/_pdf/-char/ja)、[DOI](https://doi.org/10.11517/jjsai.14.2_251)、[CiNii](https://ci.nii.ac.jp/naid/110002808179)
  - 第2・3章の、暫定的な分類を試行して見直す手順と、やりとりの中で発話を位置づける考え方を参考にする
  - 対象は課題遂行対話であり、問題解決を中心とする対話構成を雑談にそのまま当てはめない
- 徳久良子・寺嶌立太（2007）「非課題遂行対話における発話の特徴とその分析」『人工知能学会論文誌』22巻4号、425–435頁 — [本文PDF](https://www.jstage.jst.go.jp/article/tjsai/22/4/22_4_425/_pdf)、[DOI](https://doi.org/10.1527/tjsai.22.425)、[CiNii](https://ci.nii.ac.jp/naid/10022007866)
  - 第2・3章の局所的なやりとりの分析と、第4章の間接応答・問い返しと先行発話との修辞関係の分析を参考にする
  - 修辞関係は、詳述や因果など、発話内容どうしの関係を指すもので、本方針の焦点操作や語用動機と同一視しない
  - 同論文の雑談分析は、一方の話者から他方へ情報を伝達する部分を対象としており、結果を雑談全体へ無条件に一般化しない
- 井上優「モダリティ」133–150頁 — [本文PDF](https://www2.ninjal.ac.jp/takoni/DGG/09_modarityi.pdf)
  - 第1節の、命題内容に対する判断と聞き手への発話・伝達態度の区別、および同じ形式でも文脈によって用法が異なるという説明を参考にする
